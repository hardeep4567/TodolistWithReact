# Todo List – React App

A React-based frontend project for building and managing a to-do list. The application is set up with Vite and includes a modern React development environment, with supporting UI libraries for styling, navigation, and notifications.

## Tech Stack

- **React 18** – component-based UI
- **Vite** – development server and build tooling
- **React Router** – client-side routing
- **Bootstrap 5** – styling and layout utilities
- **Flowbite React** – reusable UI components
- **React Toastify** – toast notifications
- **React Slick / Slick Carousel** – carousel components

## Getting Started

The frontend application is located in the `client` directory.

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

```bash
git clone https://github.com/hardeep4567/TodolistWithReact.git
cd TodolistWithReact/client
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## Available Scripts

Run these commands from the `client` directory.

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
